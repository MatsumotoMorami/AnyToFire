# AnyToFire

本项目 AnyToFire 的功能包含：任意网的游戏档案保存与本地合并、非火网单局自动同步至 FireNet，以及旧 IIDXScore 插件的全部功能（包括 Omnifix 分数本地保存与游戏内显示）。

## 使用前准备

本地存分、初始化和保存设置可直接使用。需要跨网同步时，请先用火网进入 IIDX 建立档案，再填写火网**第三方访问码**。

将发布包中的 DLL、EXE 和 WebView2Loader.dll 一起放到 IIDX 游戏根目录，或放到游戏目录下的子目录，例如 `AnyToFire`、`modules` 或 `plugins\AnyToFire`。游戏根目录含有 `data\info\0\music_data.bin`。启动安装位置的 `AnyToFire.exe` 后，按实际启动方式配置。

- **BAT / 命令行**。在设置中选择「BAT / 命令行（手动配置）」并复制 `-k` 参数。编辑你实际用于启动 `spice64.exe` 的脚本，删除旧的 AnyToFire.dll 路径，再添加复制的参数。如果一个旧的 `-k` 中还列有其他 DLL，只从列表中移除 AnyToFire.dll。每条启动命令只保留一份 AnyToFire。若之前已在启动器的 cfg 中手动启用 AnyToFire，也请清理重复项。迁移旧版 IIDXScore 后，请手动移除脚本里单独加载 IIDXScore.dll 的参数。AnyToFire 不会读取或修改 BAT/CMD 文件。
- **cfg**。在设置中选择「cfg 配置（spicetools.xml）」，然后通过「启用该插件」管理 IIDX 配置中的 `-k`。

两种方式均使用 EXE 旁边 DLL 的绝对路径，兼容从游戏根目录或 `modules` 启动。路径含空格、非 ASCII 字符或批处理特殊字符时，会尝试 Windows 短路径。如系统无法提供可用的短路径，请把 AnyToFire 放到完整路径仅含 ASCII 且不含空格或批处理特殊字符的目录。移动安装目录后，BAT 用户需重新复制参数，cfg 用户打开软件即可刷新路径。

当前 DLL 支持 IIDX 33 的 0331、0422、0909，以及 IIDX 34 的 010-0916、012-0916、010-0917、010-1013、010-1027 和 012-1027。各版本使用独立签名，未知构建不会安装钩子。012-1027 的五组成绩接口与方法表通过离线装载验证。自动同步继续要求已校验的 AC 曲库，实际登录、结算和上传仍需实机确认。

## 单局同步

- 直接连接火网时，游戏负责原生提交及断网重试，无需第三方访问码。AnyToFire 保存单局记录，收到匹配的游戏响应后显示「已上传」。能否在游戏退出后补传取决于游戏是否保留自己的待提交记录。
- 接入非火网时，可以填写访问码并开启「自动同步非火网成绩到火网」。插件会同步符合 AC 曲库校验的单局，临时网络错误会进入重试队列。留空访问码时，这个开关不可用。
- 旧版历史记录没有来源网络字段，仍可在最近游玩列表手动选择符合条件的单局上传。

## 慎用：档案同步

设置中的“Omnifix 分数不上传服务器，只存于本地”默认开启，下次启动游戏时生效。插件用已校验的当前 AC 索引按曲目和谱面判断；确认属于非 AC 的单局先保存至兼容 IIDXScore 的本地库，并采集到最近游玩分数，再在原生 `music.reg` 组包回调中阻止网络发送。此开关同时约束当前 EA 服务器的原生提交；FireNet 自动/手动上传原本也会过滤这些曲目。AC 成绩正常提交。拦截会写入日志，不会伪造“服务器上传成功”；游戏如何展示未发送状态仍需实机验证。

游戏档案只保存每张谱面的最优成绩，无法还原每次游玩的分数与时间，也无法准确记录游玩次数。

单局上传若显示 400/404，请悬停在同步状态上查看服务端错误码与字段。中途死亡记录的 `CONFLICTING_PLAY_LOG` 是火网对游戏原始包的校验冲突；客户端会保留原始成绩，等待服务端兼容。详见 [错误排查](docs/firenet-upload-errors.md)。

列表支持点击表头切换升序／降序，选择状态在排序后保留。

设置中的“开启同一档案自动合并”默认关闭。开启后，同一服务器地址、同一 IIDX ID、同一曲库索引的原始档案会自动生成并维护一份合并结果；合并成功后，原档案自动移入 `.deleted` 并从列表移除，列表只保留合并结果；后续新档案继续并入该结果。身份不明、服务器不同或曲库不同的档案不会自动合并。EX Score 和灯取最高，BP 取最低。

“自动更新”默认开启。软件启动时在后台检查本项目最新正式 GitHub Release，下载 `AnyToFire-v版本.zip` 和对应 `.zip.sha256` 并校验 SHA-256。退出游戏与软件后，自动备份并替换 EXE、DLL 和 WebView2 加载器，保留配置、成绩、SQLite 与曲库索引。安装失败会尝试恢复旧二进制文件，详情写入安装目录的 `update.log`。关闭自动更新会取消尚未安装的更新。

发布时须同时上传 `build.ps1` 生成的 ZIP 和同名 `.zip.sha256` 校验文件；缺失校验文件时更新器不会安装。

0.3.9 提供 1013 兼容。0.3.9 修复更新请求未配置 HTTPS TLS 后端的问题；0.3.7 及更早版本需手动升级一次，此后可在启动时自动检查新版。自动更新只替换 AnyToFire 自身的三个程序文件，不更新 GSM、Playlister 或 Recorder。
