## IIDX 34 兼容更新

- 新增 20261027（1027）版 bm2dx.dll 的识别及五组成绩接口签名。
- 本次提供的 20260917（0917）版与已有签名一致，继续支持；其余已支持版本也保留。
- 两份 DLL 都通过了离线加载检查。1027 的实机登录、打歌结算和上传还待验证。火网单局上传仍要求使用已校验的原版曲库索引，本次未新增曲库白名单。

## 更新方法

如果日志仍显示 AnyToFire 0.3.0，请手动更新。退出游戏和 AnyToFire，将 ZIP 中的 AnyToFire 文件夹放到游戏根目录并覆盖同名文件，然后运行新版 AnyToFire.exe 一次。原有设置和成绩数据库会保留。

重新启动游戏后，查看 AnyToFire.log 的末尾，应看到 AnyToFire 0.3.11 启动，以及识别到 0917 或 1027。若仍显示 0.3.0，请检查实际使用的启动配置：AnyToFire 的注入项应为 AnyToFire\AnyToFire.dll，移除同一配置中指向根目录旧 DLL 的注入项。
